# aid4 — AGENTS.md

Standard Gradle multi-project Java 21 app, generated by `gradle init`.

## Naming

- Gradle `group`: `pl.informatysta.aid4` (set in `java-common-conventions`)
- One module per exercise: `sXXeYY`
- Java package: `pl.informatysta.aid4.<module>` (last segment matches the module name)
- Shared code later: a dedicated module, e.g. `:shared` → `pl.informatysta.aid4.shared`

## Modules

| Module | Type | Convention plugin | Dependencies |
|--------|------|-------------------|-------------|
| `s01e01` | application | `java-application-conventions` | commons-text, jackson-databind, dotenv-java |

Main class: `pl.informatysta.aid4.s01e01.App` (set in `s01e01/build.gradle.kts`).

## Build & test

```sh
./gradlew build              # compiles + tests all modules
./gradlew test               # all tests
./gradlew :s01e01:test       # single module
./gradlew test --tests "*PersonFilterTest"  # single test class
```

Java 21 required. JUnit Jupiter 6.0.1 via `useJUnitPlatform()`. Configuration cache is on (`gradle.properties`).

## Build conventions (buildSrc)

Convention plugins under `buildSrc/src/main/kotlin/`:
- `java-common-conventions` — Java 21 toolchain, Maven Central, JUnit Jupiter, configuration-cache-friendly
- `java-library-conventions` — common + `java-library`
- `java-application-conventions` — common + `application`

## Notes

- `gradle/libs.versions.toml` has a `[libraries]` section with Mockito; versions are hardcoded in convention plugins.
- No CI, no formatter, no linter config, no Docker, no README.
- `buildSrc` uses `kotlin-dsl` plugin but its `settings.gradle.kts` references a version catalog that has no entries yet.
- All code is `pl.informatysta.aid4.*` namespace.
