## Modules

| Module | Type | Convention plugin | Dependencies |
|--------|------|-------------------|-------------|
| `list` | library | `java-library-conventions` | none |
| `utilities` | library | `java-library-conventions` | `api(project(":list"))` |

Main class: `org.example.app.App` (set in `app/build.gradle.kts:16`).

## Build & test

```sh
./gradlew build          # compiles + tests all modules
./gradlew test           # all tests
./gradlew :app:test      # single module
./gradlew test --tests "*LinkedListTest"  # single test class
```

Java 21 required. JUnit Jupiter 6.0.1 via `useJUnitPlatform()`. Configuration cache is on (`gradle.properties`).

## Build conventions (buildSrc)

Convention plugins under `buildSrc/src/main/kotlin/`:
- `java-common-conventions` — Java 21 toolchain, Maven Central, JUnit Jupiter, configuration-cache-friendly
- `java-library-conventions` — common + `java-library`
- `java-application-conventions` — common + `application`
